# Employee Attrition Analysis – AnalystLab Africa Week 1

# Overview
Week 1 project for the AnalystLab Africa Data Science Internship Programme.

# Business Problem
ABC Manufacturing Ltd wants to understand employee attrition before investing in predictive machine learning.

# Dataset
IBM HR Analytics – Employee Attrition & Performance.
1,470 rows
35 columns
0 missing values
0 duplicate rows
Overall observed attrition: 16.1%

# Tools
Python, Pandas, NumPy, Matplotlib and Jupyter Notebook.

# Key Findings
Sales has the highest departmental attrition rate: 20.6%.
Sales Representatives have the highest job-role attrition rate: 39.8%.
Average age: 33.6 for employees who left vs 37.6 for those who stayed.
Average monthly income: $4,787 for employees who left vs $6,833 for those who stayed.
Overtime attrition: 30.5% vs 10.4% without overtime.
These are associations, not proof of causation.
